# 产品需求文档 (PRD) - AI 销售邮件自动化系统升级

## 1. 项目背景与目标
当前项目依赖外部 Manus 界面与本地 Python 脚本结合的半自动流程。本次升级的目标是将项目改造为**完全在内部闭环运行的 AI 销售邮件自动化系统**，实现 CRM 数据直连、AI 智能模板匹配、富媒体邮件生成以及智能送达率控制。

## 2. 核心用户流 (User Flow)
升级后的系统引入了交互式终端控制台（Interactive CLI），用户无需手动修改文件即可完成全流程。

1. **启动系统**：用户在终端运行 `python main.py`，进入交互式菜单。
2. **数据同步**：系统自动读取本地 CRM 数据（如 CSV），识别未发送或需要跟进的客户。
3. **智能生成**：
   * 提取历史互动记录。
   * 调用 LLM API 分析客户画像。
   * 根据规则匹配 HTML 模板并动态填充内容与图片。
   * 生成邮件草稿并保存。
4. **人工审核 (Human-in-the-loop)**：
   * 在终端界面中，系统逐条展示生成的邮件草稿。
   * 用户通过按键（如 Y 发送，N 拒绝，E 修改）进行审核。
5. **智能发送**：
   * 审核通过的邮件进入发送队列。
   * 系统执行频率控制、随机延迟和防重复检测。
   * 自动调用 SMTP 发送并记录日志。

## 3. 功能模块需求

### 3.1 核心控制台 (Interactive CLI)
* 提供清晰的终端交互界面。
* 包含“生成草稿”、“逐条审核”、“查看日志”、“配置检查”等选项。
* 替代原有手动在 CSV 中填写 `pass` 的操作。

### 3.2 客户与互动分析模块 (Customer & Interaction Analyzer)
* **输入**：客户基础信息、`email_logs.csv` (已发邮件)、`reply_logs.csv` (回复记录)。
* **处理**：调用 LLM 分析客户当前处于哪个销售阶段（如：未联系、已联系未回复、已回复）。
* **输出**：推荐的跟进策略和模板类型。

### 3.3 模板与富媒体引擎 (Template Engine)
* 引入 HTML 与 YAML 组合的模板系统（存放于 `templates/email/`）。
* 支持 `{{IMAGE:xxx}}`、`{{FILE:xxx}}` 等占位符，自动从 `assets/` 目录中匹配真实资源并嵌入。
* 目前已内置 `initial_contact` (带图版)、`follow_up` 和 `final_note` 三套标准模板。

### 3.4 智能送达率管理 (Deliverability Manager)
* **频率控制**：限制每小时/每日发送上限。
* **随机延迟**：发送邮件之间加入随机等待时间（如 30-120 秒）。
* **相似度检测**：防止短时间内发送大量完全相同的邮件文本。
* **基础 DNS 校验**：发送前检查发件域名的 SPF 记录。

## 4. 数据库与存储设计 (Data Structure)
初期继续采用轻量级 CSV/JSON 存储，为未来迁移 SQLite 做准备。

* `data/customers.csv`: 客户主数据。
* `data/drafts.json`: 存储结构化的邮件草稿（包含 HTML 源码、关联图片路径）。
* `data/email_logs.csv`: 发送历史。
* `data/reply_logs.csv`: 接收历史。

## 5. 外部接口依赖
* **LLM API**：通过 `.env` 配置，用于生成文本和分析逻辑（如 OpenAI 或其他兼容 API）。
* **SMTP/IMAP**：腾讯企业邮箱接口，用于收发邮件。
