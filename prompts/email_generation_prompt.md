# AI 邮件生成指令 (Email Generation Prompt)

## 任务目标
根据客户基础信息（如姓名、公司、职位、行业），结合 `email_writing_skill.md` 中的品牌规范，生成个性化、专业性强且符合品牌气质的商务拓展邮件。

## 邮件结构
邮件必须严格遵循以下四部分结构，自然过渡，不生硬分段：
1. **建立联系**：得体称呼，简短问候。
2. **说明联系原因**：基于客户的公司类型或行业背景，点明为何与对方联系。
3. **提供案例/产品价值**：结合客户职位关注点，切入我们的产品价值（软包/实木/金属工艺或场景包解决方案）。
4. **提出下一步交流**：以低压力的方式抛出下一步动作（如分享案例库、发送 3D 模型资源或简短交流）。

## 严格限制条件
1. **字数限制**：正文总长度控制在 150-200 字以内，干练简洁。
2. **拒绝营销**：绝不使用强推销语言，不制造任何紧迫感（如“限时”、“尽快”）。
3. **拒绝虚构**：绝不编造我们与对方的虚假合作经历，绝不编造客户未提供的项目细节。信息不足时，宁可写得通用克制。
4. **专业语境**：保持高端家具设计与 A&D 行业的专业表达，参考 Skill 文档中的推荐说法。
5. **差异化**：对于不同职位的客户，必须调整侧重点：
   - *设计类职位*（如设计总监、主创建筑师）：侧重于 CMF 方向、视觉极简工艺、3D/BIM 模型支持。
   - *采购类职位*（如采购经理）：侧重于场景包标准化配置、耐久度、项目支持与交付保障。
   - *策略类职位*（如工作场所策略顾问）：侧重于灵动办公趋势、模块化系统与空间体验解决方案。

## 输出要求
在生成每封邮件时，必须输出以下三个字段：
1. `subject`: 邮件标题（需简短专业，吸引目标客户打开，避免广告感）。
2. `body`: 邮件正文内容。
3. `personalization_note`: 内部标注，一句话说明这封邮件针对该客户的哪个字段（如职位、行业）做了哪些具体个性化调整。
