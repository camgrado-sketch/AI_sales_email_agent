## 🌟 它能为您做什么？

如果您是一名产品设计师或销售经理，每天需要处理大量潜在客户，这个工具将是您的“超级助手”：

*   **双语自动切换**：只需提供一份模板，AI 会自动生成中英双语版本。它能根据客户所在地（如上海或纽约）自动选择合适的语言，确保沟通无国界。
*   **带图邮件一键生成**：您可以直接拖入带图片的 Word 文档。助手会自动提取图片并完美嵌入邮件正文，不再有图片失效的尴尬。
*   **“零成本”批量撰写**：AI 仅在您导入模板时工作一次。之后的成百上千封邮件生成完全在本地完成，**不消耗任何 API 费用**，速度极快。
*   **人工最后把关**：每一封邮件在发出前，都会在您的浏览器中弹出预览。您可以点击确认、修改或拒绝，确保发出的每一句话都精准得体。
*   **智能状态监控**：终端顶部实时显示“健康状态”，告诉您模板是否就绪、还有多少邮件待发、收到了多少回复。

## 🚀 核心使用流程（小白上手版）

整个系统通过一个**简单的交互菜单**运行，您只需按数字键即可完成操作：

### 1. 准备模板 (一次性)
将您的开发信（Word 或 Markdown 格式）放入 `templates/import/` 文件夹。运行程序并选择 `[6] 导入模板`。AI 会自动为您生成精美的 HTML 模板。

### 2. 确认生效
在菜单中选择 `[A] 选择生效模板`。系统会记住您的选择，直到您下次更换。

### 3. 一键生成草稿
准备好客户名单（`data/customers.csv`），选择 `[1] 生成草稿`。系统会瞬间为所有客户准备好个性化的邮件内容。

### 4. 预览与发送
选择 `[2] 审核草稿`，浏览器会自动弹出邮件效果。满意后选择 `[3] 发送已审核邮件`，助手将按照模拟人工的频率安全发出。

## 🛠️ 快速安装指南

对于非开发人员，请确保您的电脑已安装 **Python 3.10+**，然后按照以下步骤操作：

### 第一步：安装依赖
打开终端（Git Bash 或终端），进入项目目录执行：
```bash
# 创建虚拟环境
python3 -m venv .venv
# 激活环境
# Linux/Mac: source .venv/bin/activate
# Windows: .venv\Scriptsctivate
# 安装必要工具
pip install -r requirements.txt
playwright install chromium
```

### 第二步：配置身份与 API
1. 复制 `.env.example` 文件并重命名为 `.env`。
2. 填写您的腾讯企业邮箱账号及**授权码**。
3. 填写您的 AI 密钥（用于导入模板）。
4. 在 `templates/sender_profile.md` 中填入您的个人职衔。

### 第三步：启动助手
```bash
python3 main.py
```

## 📂 目录结构简述

*   `data/`：存放您的客户清单（`customers.csv`）和生成的草稿。
*   `templates/import/`：**这是您最常用的文件夹**，把写好的 Word 往里扔。

## ❓ 常见问题

*   **Q: 浏览器没有自动弹出预览？**
    *   A: 系统会尝试自动打开。如果没反应，请检查终端输出的黄色文字，里面有截图路径，您可以直接打开查看。
*   **Q: 邮件变量（如姓名）没替换成功？**
    *   A: 请确保您的客户表格（CSV）中的表头与模板中的占位符（如 `CUSTOMER_NAME`）对应。
