# GRADO 商务邮件写作规范（Email Writing Skill）

本规范用于统一 GRADO CONTRACT 对外商务邮件的语言、口径与内容结构。核心原则是三条：**语言跟着客户走、表述不超出事实边界、内容跟着收件人的职责走**。

---

## 1. 语言使用规则（Language Rule）

语言选择的判断依据是**收件人的工作语言**，而不是公司注册地。判断顺序为：收件人所在办公室的工作语言 > 公司总部语言 > 行业惯例。

| 收件人情形 | 使用语言 | 说明 |
| :--- | :--- | :--- |
| 中国大陆企业、机构、设计单位 | **中文**（简体） | 邮件正文、附件命名、产品名称均用中文，产品型号保留英文原名 |
| 港澳台及新加坡华语区 | **中文 + 英文关键信息** | 正文可用中文（繁体视对象而定），产品名、材质编号、认证名称保留英文 |
| 海外企业、国际设计公司、跨国运营商总部 | **英文** | 全英文撰写，不做中英对照，避免出现中文附件名 |
| 在华外资企业的本地团队 | **英文为主，中文为辅** | 若收件人为外籍主管用英文；若为本地采购/设计团队，可中文正文＋英文附件 |
| 无法判断收件人语言背景 | **英文** | 英文是更安全的默认选项，后续根据回复语言切换 |

**执行要点**

第一，同一封邮件不要中英混排成两段对照，那会让邮件显得像群发模板。需要双语时，做法是正文单语，附件（Lookbook、规格表、报价单）提供对应语言版本。

第二，中文邮件不要直译英文句式。英文商务邮件习惯的 "I hope this email finds you well" 直译成中文会很生硬，中文开头应直接说明来意与关联点。

第三，英文邮件避免中式表达。不使用 "Dear Sir or Madam"（显得是群发），使用 "Dear + 名字"；不使用 "kindly"、"please find attached herewith" 等过时表述。

第四，回复必须与对方语言一致。如果对方用英文回复中文邮件，后续全部切换为英文。

## 2. 品牌定位与服务表述边界（Positioning & Compliance）

GRADO 是来自中国的原创设计家具品牌，专注公共空间与商业空间的软体及休闲家具，定位处于中高端原创设计品牌区间，产品调性与 Muuto、Arper、Viccarbe、Andreu World 等品牌处于同一讨论语境。

**关于服务对象的表述，必须遵守以下边界。** 除已获得客户书面授权公开的项目外，不点名具体客户，不使用"世界 500 强"、"顶级金融机构"、"服务过 XX 品牌"等具体化、排名化的表述。正确做法是描述**客户画像与空间类型**，而不是客户身份。

| 禁止表述（Don'ts） | 合规表述（Do's） |
| :--- | :--- |
| 我们服务过世界 500 强企业总部 | 我们的产品体系长期应用于跨国企业办公总部、区域总部一类的高频公共空间 |
| 我们的客户包括顶级金融机构和奢侈品牌 | 我们服务过符合金融、专业服务及高端商业零售画像的企业客户 |
| 我们和 Gensler、M Moser 有合作 | 我们的产品曾进入国际设计事务所主导的项目选品流程 |
| 我们是 XX 集团的指定供应商 | 我们具备进入大型集团供应商体系所需的合规与交付能力 |
| Our clients include Fortune 500 headquarters | Our products have been specified in workplace environments of a profile comparable to multinational corporate headquarters |
| We work with leading luxury brands | We have supplied projects in the premium retail and hospitality segment |

**表述自查三问**：这句话是否点名了未授权客户？是否使用了无法举证的排名或等级词？是否把"参与投标／进入选品库"说成了"已合作"？任何一问为"是"，必须改写。

## 3. 工艺与材质的准确表述（Craft Statements）

工艺描述是最容易失真的部分。原则是**只讲 GRADO 实际在做的工艺，讲清楚它解决了什么问题，不做等级和排名的加码**。

### 3.1 软体工艺（核心优势，可充分展开）

软体是 GRADO 的主项，可以展开描述。可谈的内容包括：面料与皮革的选型分级逻辑、海绵密度与回弹的分区配置、缝纫与包覆的接缝处理、高频使用场景下的耐久性设计、可更换外罩与易维护性、公共空间所需的耐磨与抗污处理。

可以说：我们在软体上按使用强度做分区配置，坐感与外观在长期使用后的一致性是主要控制目标。

不要说：我们的软包工艺全球领先／我们使用 Elmosoft、Steelcase 等最高阶皮革（除非该项目确实指定并采购了该面料）。

### 3.2 木质工艺（据实描述，不做等级加码）

GRADO 的木质应用集中在座椅框架、扶手、桌面及木饰面部件，常用工艺为实木部件加工、木皮饰面、成型板材与环保饰面处理，可提供 FSC 认证材料选项。

可以说：木质部件用于框架与桌面，通过实木部件与木皮饰面的组合，控制成本与稳定性，同时保留木材的温度感；可提供 FSC 认证材料选项。

不要说：我们使用 Premium Wood 顶级等级木材／全实木整体结构／稀有硬木。这类表述既无法举证，也与实际生产不符。特别注意，**不要自创或引用竞品的木材等级体系来定义自己的材料等级**。

### 3.3 金属工艺（据实描述，突出结构价值）

GRADO 的金属应用集中在椅脚、底座与框架结构，常用工艺为钢管弯管焊接、钣金成型、铝合金件、粉末喷涂与电镀处理，部分产品线使用不锈钢板成型及表面蚀刻工艺（如 CYBER 系列）。

可以说：金属结构件以弯管焊接与钣金成型为主，配合粉末喷涂做表面处理，在保证公共空间承载与稳定性的前提下让视觉尽量轻薄。

不要说：航空级铝合金／精密压铸工艺全线应用／军工级表面处理。如某产品确实使用压铸铝底座，可具体到该产品说明，但不要泛化为品牌通用工艺。

### 3.4 设计理念表述

统一口径为 **"视觉极简、结构与工艺做在看不见的地方"**。溢价逻辑来自接缝控制、坐感分区、结构耐久这三处经得起长期使用检验的细节，而不是来自材料等级的堆砌。

## 4. 按公司类型与职位角色定制内容（Audience Targeting）

这是本规范的核心工具。写邮件前先定位两个坐标：**收件人所在的公司类型**（决定谈什么项目场景）和**收件人的职位角色**（决定谈什么价值维度）。两者交叉后确定内容。

### 4.1 公司类型维度（决定"谈什么场景"）

公司类型划分参照 Arper、Viccarbe 一类品牌的实际客户结构。

| 公司类型 | 典型对象 | 核心关切 | 邮件应切入的场景 |
| :--- | :--- | :--- | :--- |
| **A. 灵活办公／联合办公运营商** | IWG（Regus、Spaces）、JustCo、德事、瑞安办公 | 单位面积产出、开业周期、耐用性与更换成本 | 大堂社交区、协作区模块座椅、咖啡吧休闲椅、电话亭周边 |
| **B. 企业终端用户（办公总部）** | 跨国企业中国区总部、科技与医药企业、专业服务机构 | 员工体验、品牌形象一致性、ESG 合规 | 前台接待、员工休闲区、协作区、高管会客区 |
| **C. 商业地产与资管方** | 开发商、写字楼资产管理方、五大行代表的业主方 | 招商竞争力、公区品质、招标合规 | 写字楼大堂公区、共享会议层、租户服务中心 |
| **D. 建筑与室内设计事务所（A&D）** | 国际及本土设计事务所 | 设计语言匹配度、图纸资源、深化配合效率 | 方案阶段的选品支持、3D／BIM 模型、材质与色彩体系 |
| **E. 酒店与高端餐饮业主／管理方** | 酒店集团、精品酒店、高端餐饮品牌 | 风格契合度、清洁维护、翻新周期 | 大堂休息区、行政酒廊、全日餐厅休闲座 |
| **F. 高端零售与品牌空间** | 时尚与奢侈品零售、汽车品牌体验中心 | 品牌调性、定制能力、全球一致性 | VIP 接待室、贵宾休息区、展陈休息座 |
| **G. 渠道与经销伙伴** | 办公家具经销商、FF&E 采购顾问、系统家具代理商 | 产品线互补性、利润空间、交期与售后 | 作为高设计感软体产品线补充其现有系统家具组合 |
| **H. 教育与医疗机构** | 高校、国际学校、医疗集团 | 安全性、耐用性、维护便利、预算合规 | 图书馆与学生休闲区、候诊区、员工休息区 |

| 角色类型 | 典型职位 | 最关心 | 邮件必须包含 | 必须避免 |
| :--- | :--- | :--- | :--- | :--- |

| 商业地产 × 资管／招商负责人 | 公区家具对楼宇品质与租户感知的提升，附大堂场景配置 |
| 设计事务所 × 主创设计师 | 材质与色彩体系、3D／BIM 模型下载、深化配合流程 |
| 设计事务所 × FF&E 采购顾问 | 规格书对接、报价结构、交期承诺 |
| 酒店集团 × 采购／项目总监 | 公区座椅的清洁维护、翻新周期内的成本表现 |

## 5. 邮件结构标准（Email Structure）

一封有效的建联邮件控制在 **150–200 字（中文）／120–160 words（英文）**，结构固定为五段，每段一到两句。

第一段，**关联点**。说明为什么写给这个人，引用一个具体事实（对方近期开业的中心、发表的设计观点、公开的项目）。这决定邮件是否被读完。

第二段，**自我介绍**。一句话说清 GRADO 是谁、做什么品类、什么定位区间，不铺陈历史。

第三段，**针对性价值**。根据 4.3 的交叉定位，只讲一个最相关的价值点，不要罗列全部优势。

第四段，**具体可交付物**。给出对方可以立刻取用的东西：Lookbook、场景配置建议、3D／BIM 模型链接、材质样卡。这一段体现专业度。

第五段，**低门槛请求**。请求一件成本极低的事：15 分钟线上交流、寄送材质样卡、或仅仅是把资料存档备用。不制造紧迫感。
