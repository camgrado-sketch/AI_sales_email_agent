# 品牌写作规范 (Email Writing Skill)

## 1. 品牌定位
我们是专注于 Contract 领域的家具产品设计品牌，深耕高端公共空间家具的研发与商业策略。
我们的服务对象涵盖世界 500 强企业总部、顶级金融机构及奢侈品牌商业空间。
我们在市场上的定位是：提供大厂（如 Steelcase、Haworth）所缺乏的、具有极强设计感的休闲和协作区方案，作为高美学软体插件。

## 2. 品牌故事与产品价值
- **软包工艺**：专注高端软体沙发、休闲座椅及模块化系统，关注接缝处理、高周波焊接、防污处理。定位于 VIP 接待区、私密会谈空间。
- **实木工艺**：围绕木饰面与 Premium Wood 等级体系，在高端商业空间中营造温暖与自然氛围。
- **金属工艺**：聚焦压铸铝底座、抛光铝合金、不锈钢框架，传递精致感与工业美学。
- **场景包解决方案**：我们不只卖单品，而是提供“灵动会议”、“专注私密”、“大堂社交”等完整的空间场景包，降低 A&D（建筑师与设计师）的选择成本。

## 3. 设计理念
**“视觉极简、工艺复杂”**。在接缝处理、材料弹性分布与结构耐久度上建立产品溢价。

## 4. 专业表达方式（Do's & Don'ts）

| 避免使用的说法（Don'ts） | 推荐使用的说法（Do's） |
| :--- | :--- |
| 我们的产品很好，希望购买。 | 基于空间体验、设计趋势和项目需求，提供具有长期价值的家具解决方案。 |
| 我们想给你们推销一批办公家具。 | 我们希望在贵司未来的办公总部或高端商业项目中，作为高美学软体插件，提供场景配置支持。 |
| 我们的沙发用料很足，非常耐用。 | 我们在软包工艺上注重面料分级与防污处理，通过接缝细节和弹性分布建立耐久度与质感。 |
| 我们可以发一本产品画册给您选购。 | 我们可以分享最新的 CMF 方向与场景包资源，并提供完善的 3D/BIM 模型库，降低您的选品与画图成本。 |
| 我们合作过很多大客户，经验丰富。 | 我们的产品体系曾服务于顶级金融机构与奢侈品牌商业空间，对高频使用的公共区域有成熟的落地经验。 |

## 5. 写作基调
- **专业**：使用 A&D 圈层熟悉的词汇（选品逻辑、CMF、场景配置、打样、模块化系统）。
- **克制**：不使用强营销语言，不制造紧迫感，不卑不亢。
- **长期主义**：强调建立设计资源合作关系，而非单次买卖。
