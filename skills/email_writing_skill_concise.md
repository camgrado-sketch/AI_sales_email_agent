# GRADO 商务邮件写作规范（精简版）

核心原则：**语言跟着客户走、表述不超出事实边界、内容跟着收件人的职责走**。

## 1. 语言规则

| 收件人情形 | 使用语言 |
| :--- | :--- |
| 中国大陆企业、机构、设计单位 | **中文简体** |
| 港澳台及新加坡华语区 | **中文 + 英文关键信息** |
| 海外企业、国际设计公司、跨国运营商总部 | **英文** |
| 无法判断语言背景 | **英文**（默认） |

同一封邮件不要中英混排成两段对照。需要双语时，正文单语，附件提供对应语言版本。

## 2. 品牌表述边界（红线）

- 不点名未授权的具体客户。
- 不使用"世界 500 强"、"顶级"、"最高阶"等无法举证的排名词。
- 不把"参与投标／进入选品库"说成"已合作"。
- 合规示例："我们的产品体系长期应用于跨国企业办公总部、区域总部一类的高频公共空间"。

## 3. 工艺表述要点

- **软体（核心优势）**：可按使用强度做分区配置，坐感与外观在长期使用后的一致性是主要控制目标。
- **木质**：实木部件与木皮饰面组合，控制成本与稳定性，保留木材温度感；可提供 FSC 认证选项。
- **金属**：弯管焊接与钣金成型为主，粉末喷涂表面处理，保证公共空间承载与稳定性。
- **设计理念**：视觉极简、结构与工艺做在看不见的地方。溢价来自接缝控制、坐感分区、结构耐久。

禁止自创或引用竞品的材料等级体系。

## 4. 受众定位速查

根据"公司类型 × 职位角色"交叉确定邮件主线：

| 收件人画像 | 邮件主线 |
| :--- | :--- |
| 联合办公运营商 × 设计总监 | 休闲软体与 Resimercial 风格匹配度，附协作区场景图 |
| 联合办公运营商 × 采购总监 | 亚太交付周期、单点小批量供货灵活度、认证清单 |
| 企业终端 × 行政/设施总监 | 高频使用区域耐久与维护方案、分批更新可行性 |
| 商业地产 × 资管/招商负责人 | 公区家具对楼宇品质与租户感知的提升，附大堂场景配置 |
| 设计事务所 × 主创设计师 | 材质与色彩体系、3D/BIM 模型下载、深化配合流程 |
| 设计事务所 × FF&E 采购顾问 | 规格书对接、报价结构、交期承诺 |
| 酒店集团 × 采购/项目总监 | 公区座椅清洁维护、翻新周期内成本表现 |
| 高端零售 × 全球设计/空间负责人 | 定制能力、跨区域一致交付、VIP 区域方案 |
| 经销商 × 渠道负责人 | 与现有系统家具互补关系、利润与授权逻辑 |

## 5. 邮件五段结构（150–200 字中文 / 120–160 words 英文）

1. **关联点**：引用一个具体事实说明为什么写给这个人。
2. **自我介绍**：一句话说清 GRADO 是谁、做什么品类、什么定位区间。
3. **针对性价值**：根据上表交叉定位，只讲一个最相关的价值点。
4. **具体可交付物**：Lookbook、场景配置建议、3D/BIM 模型链接、材质样卡。
5. **低门槛请求**：15 分钟线上交流、寄送材质样卡、或把资料存档备用。不制造紧迫感。
